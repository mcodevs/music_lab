**2026-11-13** holatiga jihozlar:
- MacBook — asosiy DAW (GarageBand, keyin Logic Pro)
- iPhone SE — g'oya yozish (Voice Memos, GarageBand iOS), Logic Remote
- AirPods Pro tipidagi quloqchin — faqat beat/mix tinglash uchun
- J6 Wireless Lavalier mikrofon — vokal yozish (receiver ulagichi Lightning yoki USB-C, aniqlanmagan)
- Yo'q: simli quloqchin, audio interfeys, MIDI klaviatura

Kelishilgan setup:
- Vokal yozishda AirPods ishlatilmaydi (Bluetooth kechikishi ~150–250 ms) — simli quloqchin kerak
- AirPods mikrofonidan yozilmaydi
- J6 noise cancel o'chiriladi; mikrofon og'izdan 10–15 sm, yon tomonda
- Xona: kiyimli shkaf / adyol bilan akustika

Yangilash tartibi: simli quloqchin → USB mikrofon (Fifine K669 / AT2020USB) → 25 klavishli MIDI klaviatura → interfeys + XLR.

**Why:** fayllar odatda telefon memo yoki lav mikrofondan keladi — ishlov berishda shuni hisobga olish kerak.
**How to apply:** kelgan vokalni tozalashda [[voice-polish-chain]], minus ustiga qo'yishda [[vocal-on-minus]] ishlat; jihoz maslahatida yuqoridagi tartibdan chiqma.
